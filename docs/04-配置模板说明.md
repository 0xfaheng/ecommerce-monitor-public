# 配置模板说明

`.env.example` 是公开模板，所有敏感值默认留空。

## 基础配置

| 变量 | 说明 |
| --- | --- |
| `ENVIRONMENT` | `development`、`staging` 或 `production` |
| `LOG_LEVEL` | 日志等级 |
| `DRY_RUN` | 是否默认 dry-run |
| `DATABASE_URL` | 数据库连接 |

## 平台配置

| 变量 | 说明 |
| --- | --- |
| `PLATFORM_A_ENABLED` | 是否启用平台 A |
| `PLATFORM_B_ENABLED` | 是否启用平台 B |
| `PLATFORM_C_ENABLED` | 是否启用平台 C |
| `GLOBAL_MIN_DELAY_SECONDS` | 全局最小访问间隔 |
| `GLOBAL_MAX_DELAY_SECONDS` | 全局最大访问间隔 |
| `MAX_ITEMS_PER_PLAN` | 每个计划最多候选数量，`0` 表示不截断 |

## 数据源配置

| 变量 | 说明 |
| --- | --- |
| `PRODUCT_LIBRARY_SOURCE` | 产品库来源 |
| `CUSTOMER_LIBRARY_SOURCE` | 客户库来源 |
| `STAFF_ROUTE_SOURCE` | 人员路由来源 |

## 外部表格配置

| 变量 | 说明 |
| --- | --- |
| `EXTERNAL_TABLE_ENABLED` | 是否启用外部表格同步 |
| `EXTERNAL_TABLE_APP_TOKEN` | 外部表格 app token，公开版留空 |
| `EXTERNAL_TABLE_ID` | 外部表格 ID，公开版留空 |

## 通知配置

| 变量 | 说明 |
| --- | --- |
| `NOTIFICATION_ENABLED` | 是否启用通知 |
| `NOTIFICATION_WEBHOOK_URL` | Webhook URL，公开版留空 |
| `NOTIFICATION_BOT_APP_ID` | 机器人应用 ID，公开版留空 |
| `NOTIFICATION_BOT_APP_SECRET` | 机器人密钥，公开版留空 |
| `NOTIFICATION_TARGET_CHAT_ID` | 群 ID，公开版留空 |
| `NOTIFICATION_ADMIN_IDS` | 管理员收件人 ID，公开版留空 |
| `NOTIFICATION_STAFF_ID_MAP` | 人员 ID 映射，公开版留空 |

## 运行产物

| 变量 | 说明 |
| --- | --- |
| `RUNS_DIR` | manifest 输出目录 |
| `LOGS_DIR` | 日志目录 |
| `EVIDENCE_DIR` | 证据目录 |
| `EXPORTS_DIR` | 导出目录 |

## 安全建议

- `.env` 永远不提交。
- 生产配置使用密钥管理系统。
- 真实推送必须设置二次确认。
- 定期检查运行目录是否被误加入 Git。
