# 字段字典

## ProductPlan

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `plan_id` | string | 巡查计划 ID |
| `product_name` | string | 产品名称 |
| `specification` | string | 规格 |
| `brand` | string | 品牌或厂家 |
| `platforms` | list[string] | 启用平台 |
| `required_keywords` | list[string] | 标题必须命中的关键词 |
| `priority` | int | 优先级 |
| `enabled` | bool | 是否启用 |

## ListingCandidate

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `platform` | string | 平台标识 |
| `product_id` | string | 平台内商品 ID |
| `title` | string | 商品标题 |
| `specification` | string | 规格 |
| `price` | string | 价格文本 |
| `shop_name` | string | 店铺名称 |
| `url` | string | 商品链接 |
| `matched_plan_id` | string | 命中的巡查计划 |
| `collected_at` | string | 采集时间 |

## NormalizedListing

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `candidate` | ListingCandidate | 原候选记录 |
| `normalized_title` | string | 清洗后的标题 |
| `price_value` | float | 标准化价格 |
| `stable_key` | string | 去重键 |
| `rule_status` | string | 规则处理结果 |
| `rule_reason` | string | 规则原因 |

## CustomerMatch

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `shop_name` | string | 店铺名称 |
| `company_name` | string | 匹配到的企业名称 |
| `region` | string | 区域或连锁归属 |
| `matched_from` | string | 匹配来源 |
| `needs_manual_review` | bool | 是否需要人工复核 |

## StaffRoute

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `region` | string | 区域 |
| `owner_role` | string | 负责人角色 |
| `support_role` | string | 支持角色 |
| `recipient_ids` | list[string] | 通知对象 ID，公开版为空或示例 |
| `missing_reason` | string | 缺失原因 |

## PushStatus

| 状态 | 说明 |
| --- | --- |
| `waiting_for_confirmation` | 等待人工确认 |
| `ready` | 已确认，等待推送 |
| `sent` | 已推送 |
| `retryable_failed` | 临时失败，可重试 |
| `failed` | 不可自动恢复 |
| `skipped` | 已被规则或状态机跳过 |
