# 模块与目录

## 公开版目录

```text
src/ecommerce_monitor_public/
├── config.py      # 环境变量和配置读取
├── models.py      # 标准数据结构
├── adapters.py    # 外部平台和外部系统接口
└── pipeline.py    # dry-run 流程编排
```

## 建议的生产模块

真实生产项目可以按以下模块扩展：

| 模块 | 职责 |
| --- | --- |
| `core/` | 配置、日志、数据库、浏览器或 HTTP 客户端管理 |
| `scrapers/` | 平台适配器，将平台结果转成统一候选记录 |
| `rules/` | 排除规则、合并规则、人工例外 |
| `matching/` | 客户库、产品库、人员库匹配 |
| `export/` | 写入表格、数据库或 BI 系统 |
| `notify/` | 群通知、个人通知、dry-run 报告 |
| `agent_app/` | 本地操作台、状态查看、运行入口 |
| `scripts/` | 定时任务、部署脚本、清理脚本 |
| `tests/` | 规则、字段、状态机和外部接口的回归测试 |

## 解耦原则

- 平台采集和业务推送分离。
- 运行态文件和源码分离。
- 真实配置和示例配置分离。
- 自动采集和人工确认分离。
- dry-run 和真实发送分离。
- 业务规则和平台适配器分离。

## 外部系统适配

外部系统建议都通过接口适配层接入：

- 表格系统：写入候选记录、读取确认状态、回写推送状态。
- 通讯系统：群通知、个人通知、图片/文本推送。
- 目录服务：查询人员 ID、部门、角色。
- 对象存储：保存截图、报告或导出文件。
- 调度系统：定时触发采集或确认后推送。
